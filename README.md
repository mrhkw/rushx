# RUSHX

RUSHX is an original 3D arcade racing game for Android, built with Godot 4.

## Prototype
- Neon City test track
- Procedural placeholder car
- Touch-ready gameplay architecture
- Keyboard controls for desktop testing
- Nitro and braking
- Mobile-compatible Godot renderer

## Planned
Career, garage, upgrades, AI racers, traffic, Desert Highway, Mountain Run, drift, drag, police chase, save system, achievements and later online multiplayer.
